# 💻 Web Development Bootcamp

This repository documents my progress through a Python Web Development Bootcamp focused on practical programming, problem-solving, and building web applications with Python and Django.

The work is organized by **week** and **day** so labs, assignments, projects, and practice files are easy to locate.

## 📁 Repository Structure

```text
WebBootcamp/
├── Week1/
├── Week2/
├── Week3/
├── Week4/
├── Week5/
├── Week6/
└── Week7/
```

Each week contains the work completed during that week.

Example:

```text
Week2/
├── Day1/
│   ├── Assignment/
│   └── Project/
├── Day2/
├── Day3/
├── Day4/
└── Day5/
```

Assignments and projects are placed inside the day they belong to whenever possible.
